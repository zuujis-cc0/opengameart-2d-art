Connect-4 Sprites
-----------------

2D sprite graphics for the classic game 4-in-a-row or Connect-4,
includes 8 colored discs and 8 colored medals.
Note that color blind accessibility has been taken into account,
both by using symbols and by opposing color (maximum color contrast) per disc pair.
Originally used in Tic-Tac-Tumble (html5/web, 2024)

You may use these graphics in personal and commercial projects.
Credit would be appreciated but is not mandatory.
