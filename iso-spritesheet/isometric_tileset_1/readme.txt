About This Tileset

This package contains isometric tileset built specifically for Godot but probably can be imported to other game engines.

To make setup painless, the ZIP includes screenshots of the exact import settings, TileSet configuration, and project options used during testing. These screenshots are located in the /screenshots/ folder inside the ZIP, along with this README.

You can ignore any physics, or collision settings seen in the screen shots.. basically the size, margin, and separation settings are what is needed.

Two Rendering Variants Included
To support different art directions and project needs, the tileset is provided in two distinct projection styles:

1. X60 / Y0 / Z45 Variant
A stylized isometric look using a 60° tilt and 45° rotation, giving slightly more visible top‑surface area and a softer, more game‑friendly perspective.

2. True Isometric Variant
Rendered using mathematically correct isometric projection, with equal axis foreshortening and a classic 2:1 pixel ratio appearance.
